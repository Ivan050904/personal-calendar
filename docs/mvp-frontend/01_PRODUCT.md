# Product

Personal Calendar — приложение для планирования жизни.

Главный сценарий: пользователь открывает приложение и сразу видит сегодняшний день с временной шкалой и запланированными делами.

Приложение не является только Google Calendar-клоном: кроме событий есть планы с чек-листами, задачи без времени и пользовательские списки.

## Основные разделы

- Календарь
- Задачи
- Списки
- Корзина
- Настройки

## Календарь

Виды:
- День
- Неделя
- Месяц

При запуске открывается Сегодня.

Первый день недели — понедельник.

## Платформы

Один responsive web application:
- desktop;
- mobile.

На мобильном календарь должен поддерживать свайп между соседними днями. На desktop — обычная мышь/клавиатура.

## MVP без аккаунта

Первая версия работает без авторизации. Данные хранятся локально.

Архитектура должна позволять позднее подключить аккаунт и единую серверную БД без переписывания доменной логики.
