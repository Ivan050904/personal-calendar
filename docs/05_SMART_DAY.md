# Smart Day — «Сейчас»

Вопрос экрана: «Что я сейчас должен делать?»

Если start <= now < end:
- title
- start/end
- elapsed
- remaining

Показывать следующий Event/Plan.

Если текущего объекта нет: `Сейчас свободно`.

All-day и date-only Task не считаются текущей временной активностью.

При overlap не скрывать данные и не придумывать автоматический приоритет; использовать существующее правило UI.

Обновлять в реальном времени. Никакой автоматической перестройки расписания.
