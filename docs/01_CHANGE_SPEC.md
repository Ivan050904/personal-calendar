# Change Spec — Smart Day + AI + Backend

## Цель
Добавить к существующему календарю:
1. экран «Сейчас»;
2. прогресс планов;
3. FastAPI backend;
4. MySQL persistence;
5. специализированный AI для создания/изменения/удаления;
6. голосовой ввод через локальный Whisper.

## Backend
Фиксированный MVP-стек:
- Python
- FastAPI
- Pydantic v2
- SQLAlchemy 2.x
- Alembic
- MySQL 8.x
- pytest + HTTPX
- Uvicorn

**Docker не нужен.** Для одного пользователя локальный MySQL достаточен.

## Smart Day
Главный экран показывает текущее локальное время, текущий Event/Plan, начало/конец, elapsed/remaining и следующий объект. Если текущего объекта нет — `Сейчас свободно` + следующий объект. Это вычисляемое представление, новая сущность не создаётся. Никакой автоматической перестановки расписания.

## Progress
Plan показывает `completed / total` и процент. Процент не вводится вручную.

## AI
Разрешены:
- CREATE/UPDATE/DELETE Event;
- CREATE/UPDATE/DELETE Plan;
- CREATE/UPDATE/DELETE Task;
- CREATE/UPDATE/DELETE List.

AI не является общим чат-ботом и не отвечает на погоду, новости и другие общие вопросы. Ответ вне домена: `Я могу помогать только с календарём, планами, задачами и списками.`

Пользователь по возможности явно говорит тип: `создай событие`, `создай задачу`, `создай план`, `создай список`. Если тип неоднозначен — спросить.

AI не придумывает отсутствующие критические значения:
- `завтра вечером` → спросить точное время;
- `после работы` → спросить время;
- `на два часа` без старта → спросить старт;
- `с 15 до 17` без даты → спросить дату.

`по вторникам` распознаётся как recurrence; `бесконечно` → never.

## Mutation pipeline
AI → Structured Action → Backend Validator → Draft → User Confirmation → Domain Service → DB.

AI никогда не пишет в БД напрямую.

## Draft
Карточка маленькая:
- что будет сделано;
- дата/время;
- recurrence;
- важные поля;
- `Создать/Подтвердить`;
- `Изменить`;
- `Отмена`.

Create/Update/Delete выполняются только после явного подтверждения.

После подтверждения:
- операция выполнена;
- карточка закрыта;
- сообщение `Событие создано` (или аналог);
- следующий ввод — новая команда.

После отмены:
- объект не меняется;
- Draft закрывается;
- следующий ввод — новая команда.

`+ Новая команда` — только необязательный escape hatch.

## Update/Delete
AI не получает DB access. Он выдаёт `TargetSelector`; backend выполняет контролируемый поиск кандидатов. Если 0 — уточнение, если 1 — Draft, если несколько — выбор пользователя.

Recurring update/delete всегда требует scope:
- только это вхождение;
- это и следующие;
- вся серия.

## Voice
Frontend записывает до ~20 секунд → backend → локальный Whisper → текст → тот же AI pipeline. Аудио по умолчанию не сохраняется. Модель Whisper выбирается после benchmark реального железа.

## Совместимость
Не ломать существующий frontend. Сохранить текущую Repository abstraction и IndexedDBRepository; добавить ApiRepository без переписывания domain logic. Backend проектировать пригодным для будущего объединения с большой системой.

## Definition of Done
Код + targeted tests + regression + typecheck + lint + build + миграции + документация + changelog. Нельзя удалять/ослаблять тесты ради зелёного результата.
