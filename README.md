# Personal Calendar — Cursor Project Pack

Это проектный пакет для разработки Personal Calendar через AI-агента.

## Как использовать

1. Положи эти файлы в корень проекта.
2. Сначала дай Cursor `prompts/START.md`.
3. Агент читает `AGENTS.md` и `development/CURRENT_TASK.md`.
4. Агент выполняет только текущую задачу.
5. После успешной проверки он обновляет CURRENT_TASK и останавливается.
6. Для продолжения отправляй тот же `prompts/START.md`.

## Если агент начал выдумывать

Отправь:

> Остановись. Перечитай AGENTS.md, CURRENT_TASK.md и DECISIONS.md. Продолжай только в рамках текущей задачи. Не меняй архитектуру и продуктовые требования без документированного решения.

## Если нужно полностью перепроверить волну

Отправь:

> Выполни regression-проверку текущей волны согласно её требованиям. Ничего нового не добавляй. Исправляй только дефекты текущей реализации. После проверки предоставь отчёт и остановись.

## Важное

Этот пакет — проектная спецификация для агента, а не пользовательская инструкция. Не требуется, чтобы пользователь понимал каждую техническую деталь.
